\# 🚀 실시간 가상자산 트레이딩 대시보드



이 프로젝트는 바이낸스와 업비트의 시세 데이터를 실시간으로 모니터링하고 개인 자산을 관리하는 도구입니다.



\## 📸 스크린샷

!\[대시보드 메인 화면](./images/Upbit_Manager_업비트_매니저.png)

> 실시간 차트와 오더북, 그리고 자산 현황을 한눈에 확인할 수 있습니다.



\## ✨ 주요 기능

\- \*\*실시간 시세 연동:\*\* 업비트(Upbit) 및 바이낸스(Binance) API 활용

\- \*\*오더북 시각화:\*\* 매수/매도 잔량을 직관적인 그래프로 표시

\- \*\*자산 관리:\*\* 보유 코인(ADA, XEC 등)의 수익률 및 평가 손익 자동 계산

\- \*\*시스템 로그:\*\* 가격 변동 및 상태 변화 실시간 알림



\## 🛠 사용 기술

\- \*\*Language:\*\* C# 14

\- \*\*Framework:\*\* .NET 10

\- \*\*Database:\*\* Entity Framework Core 9 (EF Core 9)

\- \*\*IDE:\*\* Visual Studio 2022 Preview
